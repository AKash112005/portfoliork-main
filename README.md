# 🌐 Akash's Portfolio

This is my personal portfolio website built with **React + Vite + TailwindCSS**.  
It showcases my **skills, projects, certifications, and contact information** in a clean and responsive design.  

---

## 🚀 Features

- 🎨 Modern UI with **TailwindCSS**
- 🌌 Animated **star background** for a unique look
- 📑 Sections:
  - Hero Section – introduction
  - About Me – short bio
  - Skills – frontend & programming languages
  - Projects – portfolio of my work
  - Certifications – view my certificates
  - Contact – get in touch with me
- 📱 Fully **responsive** (desktop + mobile)
- 🌓 Light/Dark mode support
- 🔗 Links to external certifications and resume

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** TailwindCSS
- **Icons:** [lucide-react](https://lucide.dev)
- **Animations:** Custom CSS / React hooks
- **Deployment:** Vercel / Netlify / GitHub Pages
